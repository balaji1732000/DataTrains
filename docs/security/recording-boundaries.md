# Recording boundaries

- Record only after explicit, versioned consent.
- Keep a permanent recording indicator and immediate pause/stop controls.
- Scope recording to assigned tasks and controlled test accounts.
- Enforce application allowlists and denylists.
- Never capture the clipboard by default.
- Deny password managers, banking, email, private messaging, and system credential dialogs.
- Prefer synthetic inputs and outputs; quarantine sessions that may contain personal data.
